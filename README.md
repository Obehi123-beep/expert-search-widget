# Expert Listing - Frontend Property Search Widget

A lightweight, high-performance typeahead and autocomplete search component built with **React** and **Vite**, tailored for real estate discovery. 

🔗 **Live Demo:** [https://expert-search-widget.vercel.app](https://expert-search-widget.vercel.app)

## 🚀 Features
- **Instant Filtering**: Real-time search filtering across Lagos property listings (locations, property types, and titles).
- **Custom UI / UX**: Styled to match modern proptech portals with custom teal/emerald color palettes, focus rings, and badges.
- **Modular Architecture**: Clean separation of concerns with dedicated components, structured property datasets, and global variables.
- **Keyboard & Accessibility Ready**: Designed for smooth user interactions.

## 🛠️ Tech Stack
- **React (Vite)** for rapid component rendering and state management.
- **CSS3** with custom root variables and responsive layouts.
